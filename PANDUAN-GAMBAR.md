# Panduan Mengganti Gambar CBB CERIYA

Semua gambar yang perlu diganti berada di folder:

`public/images/photos/`

Cara menggantinya:

1. Siapkan foto asli dalam format **WebP**.
2. Sesuaikan ukuran atau rasio gambar mengikuti tabel di bawah.
3. Ubah nama foto agar **sama persis** dengan nama file dummy.
4. Timpa file dummy di folder `public/images/photos/`.
5. Jangan mengubah nama, ekstensi `.webp`, atau lokasi foldernya.

Web akan otomatis memakai foto baru tanpa perlu mengubah HTML, CSS, atau JavaScript.

## Tips Foto

- Gunakan foto terang, tajam, dan tidak buram.
- Untuk galeri dan fasilitas, letakkan subjek utama di bagian tengah agar tidak terpotong.
- Untuk foto testimoni, gunakan foto wajah dengan ruang yang cukup di sekeliling kepala.
- Kompres foto WebP dengan kualitas sekitar 75–85% agar web tetap cepat.
- Pastikan sudah mendapat izin sebelum menampilkan foto anak, orang tua, atau tenaga pengajar.
